# The Most Informative Subgraph of a Vertex-Colored Graph: Definition, Bounds, and Estimation

This repository contains the source code, experimental data, and figure-generation scripts associated with the paper **"The Most Informative Subgraph of a Vertex-Colored Graph: Definition, Bounds, and Estimation."**

The repository is organized to support reproducibility of the experimental results and figures presented in the paper.

## Repository Structure

```text
most-informative-subgraph/
├── README.md
├── requirements.txt
├── .gitignore
├── data/
├── src/
└── figures/
```

- **`data/`** — Input datasets and experimental results.
- **`src/`** — Source code for generating data and running experiments.
- **`figures/`** — Scripts for reproducing the figures presented in the paper.
- **`requirements.txt`** — Python dependencies required to execute the code.

## Installation

Clone the repository:

```bash
git clone https://github.com/TalCohenYosef/most-informative-subgraph.git
cd most-informative-subgraph
```

Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Reproducing the Experimental Results

The scripts and instructions for generating the experimental results will be provided in the `src/` directory.

## Reproducing the Figures

The scripts used to reproduce the figures presented in the paper will be provided in the `figures/` directory.

## Data

The `data/` directory will contain the experimental datasets and results required for reproduction.
