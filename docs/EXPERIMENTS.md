# Saved-result analysis and figure reproduction

## Scope

This repository supports dataset generation, analysis of the saved experimental
results, and reproduction of Figures 2–6. It does not include drivers for
rerunning the computationally expensive experiments. The original experiments
used Subgraph Filter Suite commit
`b4a90b08a2d418b137f06edd09044da400b567d8`.

The saved summaries under `data/results/` remain the results associated with
the paper. Replacement GNP datasets generated by this repository are stochastic
and are not the original inputs underlying those summaries.

## Saved results

- `data/results/vista/`: VISTA survival and timing summaries.
- `data/results/graphlets/`: Graphlets filtering outcomes and timings. A value
  of `1` means rejected/negated and `0` means survived.
- `data/results/vista_plus/`: twelve VISTA+ saved-result runs. Their
  `run_config.json` files and `configs/vista_plus.yml` preserve the campaign
  parameters and output semantics.
- `data/results/realworld/`: BookChild, SportsFit, and ogbn-arxiv summaries.
- `data/results/theory/`: saved theory-score and aggregate timing inputs.

## Analysis utilities

Reusable readers and panel-building utilities are located in
`figures/analysis/`:

- `result_readers.py`: VISTA and Graphlets saved-result readers used by
  Figures 3 and 4.
- `figure_03_vista_panel.py`: Figure 3 VISTA panel construction.
- `figure_06_matrix.py` and `figure_06_membership.py`: Figure 6 matrix and
  membership-distribution analysis.
- `build_gnp_manifest.py` and `build_repository_checksums.py`: optional data
  inventory utilities.

Figure scripts read the compact files in `data/results/` directly. The
figure-to-input mapping is documented in `FIGURE_MANIFEST.md`.

## Figure reproduction

Run from the repository root:

```bash
python figures/figure_02/plot.py
python figures/figure_03/plot.py
python figures/figure_04/plot.py
python figures/figure_05/plot.py
python figures/figure_06/plot.py
```

Use each script's `--output` option to write to a temporary path without
replacing the saved manuscript PNG.

## Reproducibility boundary

Figure reproduction from saved results does not independently rerun the
underlying VISTA, Graphlets, VISTA+, real-world, theory, or timing experiments.
Known scientific limitations are documented in `REPRODUCIBILITY.md`.
